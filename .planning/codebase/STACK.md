## Configuration

**Environment:**
- Standard ASP.NET Core configuration: `appsettings.json` -> `appsettings.{Environment}.json` -> environment variables (use `__` as the section separator) -> command line.
- `ASPNETCORE_ENVIRONMENT` is set to `Development` in `launchSettings.json`.
- Configuration keys read by the code (names only):
  - `ConnectionStrings:DefaultConnection` (`Tripory.Persistence/DependencyInjection.cs`; falls back to a hard-coded local default if missing, see CONCERNS)
  - `JwtOptions:SecretKey`, `JwtOptions:Issuer`, `JwtOptions:Audience`, `JwtOptions:ExpiryMinutes`, `JwtOptions:RefreshTokenExpiryDays` (`Tripory.Infrastructure/Configurations/JwtOptions.cs`, section name `JwtOptions`)
  - `DestinationCatalog:CoverImageBaseUrl` (`Tripory.Infrastructure/Configurations/DestinationCatalogOptions.cs`; must be absolute https URL ending with `/`, validated on start)
  - `Cors:AllowedOrigins` (`Tripory.API/Cors/CorsAllowedOriginsOptions.cs`)
  - `AuthRateLimitOptions:BffSharedSecret` plus `Login`, `Register`, `RefreshToken` rules (`Tripory.API/RateLimiting/AuthRateLimitOptions.cs`; defaults 5/60s, 3/3600s, 20/60s)
- Options validated with `ValidateOnStart()` in `src/Services/Tripory/Tripory.Infrastructure/DependencyInjection.cs`.
- Secret-bearing keys (`JwtOptions:SecretKey`, `ConnectionStrings:DefaultConnection`, `AuthRateLimitOptions:BffSharedSecret`) currently have development values committed in `appsettings*.json`. Override them via environment variables outside local development.
- No `.env` file in the repo; `.env` is gitignored (`.gitignore`). `docker-compose.yml` contains inline Postgres credentials (`POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD`).

**Build:**
